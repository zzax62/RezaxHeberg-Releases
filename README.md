# RezaxHeberg

Distribution des versions Windows de RezaxHeberg.

Ce dépôt contient uniquement les informations de distribution et les fichiers compilés dans Releases. Les sources du projet et la clé privée de publication ne sont pas publiées dans ce dépôt.

Les mises à jour sont vérifiées avec Ed25519 et SHA-256. Les exécutables ne disposent pas de signature Windows Authenticode.

Les connexions réelles aux jeux et à Discord nécessitent une configuration par le propriétaire ; consulter les notes de chaque version.
